## 2. SCRIPTS DE WHATSAPP PRONTOS PARA USAR

> Copie e cole nas Respostas Rápidas do WhatsApp Business (`!atalho`) ou envie direto.
> Substitua `[produto]`, `[preço]`, `[bairro]` conforme a conversa.

### 2.1 Saudação / Qualificação

```
Olá! 👋 Sou o [Nome], da [Loja].
Vendo eletrônicos em Manaus com entrega no mesmo dia e garantia 30 dias.
Qual produto você procura?
```

```
Oi! Tudo bem? 😊
Esse produto está disponível sim!
✅ Preço: R$ [preço]
✅ Entrega hoje via motoboy (R$ 15–20)
✅ Garantia local 30 dias
✅ PIX ou dinheiro na entrega
Quer reservar?
```

### 2.2 Qualificação de orçamento (smartwatch)

```
Qual seu orçamento?
A) Até R$ 60 → D20 / D18s
B) R$ 60–120 → S11 Mini / CU10 Ultra
C) R$ 120–200 → W29s / S11 Pro
D) Acima de R$ 200 → Imeson premium
```

### 2.3 Entrega e pagamento

```
Sim! Entrego na [bairro] no mesmo dia via motoboy.
Taxa: R$ 15 (ou R$ 20 pra bairros mais longe).
Tempo: 2 a 4h após confirmar o PIX.
Quer reservar? Já te mando o link de pagamento.
```

```
Pagamento: PIX ou dinheiro na entrega.
Também aceito cartão na entrega (+2%).
Confirma o pedido que eu fecho a reserva pra você.
```

### 2.4 Upsell de kit

```
Ótima escolha! Que tal levar com 10% de desconto no combo?
Kit [produto] + Fone M19 por R$ 89,90
Economiza R$ 14,90 e ainda ganha frete grátis!
Quer aproveitar?
```

### 2.5 Garantia / troca

```
Tudo tem 30 dias de garantia local.
Se der qualquer defeito, traz que eu troco na hora — sem burocracia.
Pode comprar tranquilo. 👍
```

### 2.6 Fechamento (envio de PIX)

```
Perfeito! Já reservei o seu. 🙌
Manda o PIX pro número [número] (chave: [chave])
Assim que cair, eu descolo o motoboy pra [bairro].
Tempo previsto: 2–4h. Qualquer coisa me avisa aqui!
```

### 2.7 Pós-venda

```
E aí, [Nome]! Tudo certo com seu [produto]?
Se precisar de qualquer coisa, estou aqui.
Marca a gente pros próximos e indica pra um amigo! 😉
```

### 2.8 Escala para você (não automatizar)

| Situação             | Resposta manual                                            |
| ---------------------- | ---------------------------------------------------------- |
| Negociar preço        | "Vou consultar o melhor preço pra você e já volto!"     |
| Defeito/reclamação   | "Sinto muito! Vou resolver isso agora, um momento."        |
| Troca por outro modelo | "Claro, me conta o que você quer que eu vejo o estoque."  |
| Venda > R$ 200         | "Perfeito! Vou te passar todos os detalhes pelo WhatsApp." |

```
NOME: [Produto] ([Variação])
CÓDIGO: [código do fornecedor]

FOTO: foto real do produto (fundo limpo)
```

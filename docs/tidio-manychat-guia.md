# Tidio vs ManyChat — Guia Prático para Vendas em Manaus

> Comparação detalhada de duas ferramentas de automação de chat/messenger para o seu negócio de eletrônicos em Manaus.

---

## 1. TIDIO — Visão Geral

### O que é
Tidio é uma ferramenta de chat multicanal que combina:
- **Chat ao vivo** para atendimento humano
- **Chatbots com IA** para respostas automáticas
- **Integração com WhatsApp, Messenger, Instagram e email**
- **Painel unificado** onde você vê todas as mensagens de todos os canais em um só lugar

### Como funciona no seu caso

```
Cliente envia mensagem no WhatsApp/FB/OLX
    ↓
Tidio captura a mensagem
    ↓
IA do Tidio analisa e responde (ou escala para você)
    ↓
Você vê tudo no painel do Tidio (celular + PC)
```

### Canais suportados

| Canal | Integração | Observação |
|-------|-----------|------------|
| **WhatsApp Business** | ✅ Oficial | Requer conta Business API |
| **Facebook Messenger** | ✅ Nativa | Conexão direta com página do FB |
| **Instagram Direct** | ✅ Nativa | Mensagens do Instagram |
| **Chat do site** | ✅ Widget | Se você tiver site |
| **Email** | ✅ Sim | Para follow-up |
| **OLX** | ❌ Indireto | Requer workaround (ver seção 4) |

### Planos e Preços

| Plano | Custo | Mensagens/mês | Recursos |
|-------|-------|---------------|----------|
| **Gratuito** | R$ 0 | 100 conversas | Chat básico, 1 operador, chatbots simples |
| **Starter** | ~$29/mês (~R$ 145) | Ilimitadas | Chatbots avançados, IA, analytics |
| **Growth** | ~$59/mês (~R$ 295) | Ilimitadas | Tudo + campanhas, segmentação |
| **Tidio+** | ~$99/mês (~R$ 495) | Ilimitadas | Tudo + IA avançada, gerente de conta |

### Vantagens para o seu negócio

✅ **Multicanal** — WhatsApp + Messenger + Instagram em um só painel
✅ **IA incluída** — respostas automáticas inteligentes sem precisar configurar fluxos complexos
✅ **Gratuito para começar** — 100 conversas/mês é suficiente para testar
✅ **Fácil de usar** — interface visual, sem código
✅ **App mobile** — você responde clientes pelo celular
✅ **Analytics** — vê tempo de resposta, taxa de conversão, etc.

### Desvantagens

❌ **100 conversas/mês no gratuito** — se vender mais de ~3–4 produtos/dia, ultrapassa rápido
❌ **IA limitada no gratuito** — respostas automáticas básicas, sem contexto do catálogo
❌ **Integração com OLX limitada** — não há integração direta, precisa de workaround

### Como implementar no seu negócio

**Passo 1:** Criar conta no Tidio (tidio.com)
**Passo 2:** Conectar WhatsApp Business (via QR code)
**Passo 3:** Conectar página do Facebook (se tiver)
**Passo 4:** Configurar chatbot básico:
- Saudação automática
- Perguntas frequentes (preço, entrega, garantia)
- Escalação para atendimento humano
**Passo 5:** Testar com amigos/família
**Passo 6:** Ativar para clientes reais

**Tempo estimado:** 2–3 horas de configuração

## 2. MANYCHAT — Visão Geral

### O que é
ManyChat é uma ferramenta especializada em **automação de Facebook Messenger e Instagram Direct**. É a mais popular para quem vende via redes sociais.

### Como funciona no seu caso

```
Cliente envia mensagem no Messenger/Instagram
    ↓
ManyChat captura a mensagem
    ↓
Fluxo pré-definido ou IA responde
    ↓
Cliente interage com bot ou é escalado para você
```

### Canais suportados

| Canal | Integração | Observação |
|-------|-----------|------------|
| **Facebook Messenger** | ✅ Nativa | Integração perfeita com página do FB |
| **Instagram Direct** | ✅ Nativa | Mensagens do Instagram |
| **WhatsApp** | ❌ Não suporta | Apenas Messenger + Instagram |
| **SMS/Email** | ✅ Sim | Para campanhas |
| **Chat do site** | ✅ Widget | Se você tiver site |

### Planos e Preços

| Plano | Custo | Contatos | Recursos |
|-------|-------|----------|----------|
| **Gratuito** | R$ 0 | Até 1.000 | Fluxos básicos, broadcast, growth tools |
| **Pro** | ~$15/mês (~R$ 75) | Até 10.000 | Tudo + custom domain, remoção de marca |
| **Business** | ~$145/mês (~R$ 725) | Ilimitados | Tudo + suporte prioritário |

### Vantagens para o seu negócio

✅ **100% gratuito para começar** — até 1.000 contatos sem pagar nada
✅ **Especializado em FB/Instagram** — onde você já vende
✅ **Fluxos visuais** — você desenha a conversa como um diagrama
✅ **Growth Tools** — ferramentas para crescer lista de contatos
✅ **Broadcast** — envio de mensagens para múltiplos contatos
✅ **Integração nativa com FB** — funciona perfeitamente com anúncios do FB Marketplace

### Desvantagens

❌ **NÃO funciona com WhatsApp** — se o cliente prefere WhatsApp, você precisa de outra ferramenta
❌ **IA limitada no gratuito** — respostas baseadas em fluxos pré-definidos, não IA generativa
❌ **Depende do FB** — se o FB muda a API, pode quebrar
❌ **Curva de aprendizado** — fluxos visuais são poderosos mas requerem prática

### Como implementar no seu negócio

**Passo 1:** Criar conta no ManyChat (manychat.com)
**Passo 2:** Conectar página do Facebook (autorizar app)
**Passo 3:** Conectar Instagram (se tiver)
**Passo 4:** Criar fluxo básico:
- Fluxo de boas-vindas (saudação + menu de produtos)
- Fluxo de consulta de preço
- Fluxo de entrega
- Fluxo de garantia
- Escalação para atendimento humano
**Passo 5:** Configurar growth tools:
- Comentários no FB → dispara mensagem automática
- Anúncios do FB → dispara fluxo
**Passo 6:** Testar e ativar

**Tempo estimado:** 3–4 horas de configuração

## 4. COMO USAR COM OLX (workaround)

OLX não tem integração nativa com Tidio ou ManyChat, mas existem alternativas:

### Opção A — Notificações do app OLX
- Baixar app OLX no celular
- Ativar notificações push
- Quando cliente envia mensagem, você recebe notificação instantânea
- Responder pelo app OLX

### Opção B — Usar número de WhatsApp no anúncio OLX
- No anúncio OLX, colocar seu número do WhatsApp Business
- Cliente clica e vai direto para o WhatsApp
- Tidio/ManyChat captura a mensagem
- IA responde automaticamente

### Opção C — Redirect do chat OLX
- No chat OLX, responder com: "Para atendimento mais rápido, me chama no WhatsApp: [seu número]"
- Cliente vai para o WhatsApp
- Automação funciona
